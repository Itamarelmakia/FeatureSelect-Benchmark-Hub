# Data

The stability analysis uses datasets from two sources:

## Real-data experiments (Stage R2)

Three p≫n datasets, expected at the following local paths under the hub's `data/`
directory. These files are **not** committed to the public Git repository — download and
populate the benchmark dataset archive first (see
[../../../data/README.md](../../../data/README.md)):

| Dataset | Path | Source | n | p |
|---------|------|--------|---|---|
| colon | `data/scikit-feature/colon.mat` | scikit-feature benchmark | 62 | 2000 |
| PeriodChanger | `data/UCI/PeriodChanger.mat` | UCI | varies | high-d |
| SMK-CAN-187 | `data/scikit-feature/SMK-CAN-187.mat` | scikit-feature benchmark | 187 | 19993 |

All three datasets are loaded with **raw signed X** (`np.abs(X)` is intentionally
not applied). Labels are remapped to `{0, 1}` via a 0-based encoder.

## Synthetic control data

Generated by `scripts/make_synthetic_control.py`. Not committed to git (large,
fully reproducible from the generator + fixed seed).

**Planted structure (default / smoke mode):**
- N = 200 samples, P = 2000 features
- 5 true-core features (2 solo, 3 anchored)
- 12 proxy features (3 groups × 4 proxies per group)
- 15 weak-signal features
- 1968 pure-noise features

**SNR grid (v1f mode, `--grid-v1f`):**
- alpha = 2.5 (HIGH), 0.6 (MID), 0.35 (LOW) plus a matched null control
- 8 generation seeds per cell

Generated datasets are written to `results/article_stability/synthetic_control/datasets/`
at the hub root.

## Note on data leakage

Feature selection is fit **only on the training split** of each resample.
The classifier is trained only on the selected training features.
Evaluation is on the held-out test split only.
No data leakage by design.
